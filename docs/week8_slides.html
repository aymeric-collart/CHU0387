Automating with “for loops”

To generate links for the whole year, we use a for loop. Every loop has three basic components:

  1. The List: The group of items you want to work through.

  2. The Action: The specific job you want to do for a single item.

  3. The Loop: The process that automatically repeats the action for the next item.

Creating the Dates Loop

We nest loops for Days, Months, and Years to generate all dates:

Dates_total <- data.frame(matrix(ncol = 1, nrow = 0))
Year <- 2024
Month <- 1:12
Day <- 1:31

for (a in 1:length(Day)){
  for (b in 1:length(Month)){
    for (c in min(Year):max(Year)){
      Dates <- paste0(c, "-", b, "-", a)
      Dates <- as.data.frame(Dates)
      Dates_total <- rbind(Dates_total, Dates)
    }
  }
}

Dates_total <- as.character(Dates_total$Dates)

Scrape through all the pages with For Loop

When scraping thousands of pages, broken links happen. We wrap our loop in tryCatch() so R skips errors instead of crashing completely:

Article_total <- data.frame()

for (j in 1:length(article_overview_unique$news_url)){

    temp <- read_html(article_overview_unique$news_url[j])
    
    # time of news
    news_time <- temp %>% 
      html_nodes("time") %>% 
      html_text(trim = TRUE)
    
    # class of news
    news_class <- temp %>% 
      html_nodes(".part_menu_5") %>% 
      html_nodes("strong") %>%
      html_text(trim = TRUE)
    
    # title 
    news_title <- temp %>% 
      html_nodes("h1") %>% 
      html_text(trim = TRUE)
    
    # content 
    news_body <- temp %>% 
      html_nodes('div[itemprop="articleBody"]') %>% 
      html_text(trim = TRUE)
    
    # url
    news_url <- temp %>% 
      html_nodes("div.block div.block_content div.part_list_2 h3") %>% 
      html_nodes("a") %>%
      html_attr("href")
    
    Article <- (data.frame(time = news_time,
                           class = news_class,
                           title = news_title,
                           body = news_body,
                           url = article_overview_unique$news_url[j]))
    Article_total <- rbind(Article_total, Article))
  
}
