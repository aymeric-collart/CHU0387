1. What does “cleaning” mean?

Why the need to clean the data?

Even with careful scraping code, raw data contain noise and format issues. Why?

Reason (a) Inconsistent structure

Most webpages share a consistent structure, but a few pages may be slightly different.

Reason (b) Shared HTML nodes

Unnecessary parts were coded under the same HTML nodes as our target text.

Reason (c) Simpler scraping

It is often much easier to scrape broadly first and clean the data afterward.

3 Main Tasks Before Analysis

📐 1. Arrange Format

The raw table structure is not suited for analysis and needs reshaping.

🧹 2. Remove Noise

Unnecessary data must be filtered out so they do not skew the results.

🏷️ 3. Add Annotations

Simple metadata columns help both the cleaning and analysis processes.

Principle 1: We clean, we don’t fish!

🔍 Don’t over-clean

When removing unnecessary data, we might accidentally delete much more than we thought.

👉 Check each time that you are not removing too much!

🙈 Watch out for bias

When we already have an idea of the results, we might treat counterexamples as “errors” to delete.

👉 This is completely wrong: the cleaning process must be blind!!

Principle 2: Be aware of the final format

In R: 1 row = 1 data point

  • A data point can be a whole text, a paragraph, or a sentence.
  • Every column on that row describes that same data point.
  • Never split the same data point across two rows!

Suitable format (fake data):

Date Article Sentence … Link
2024-01-01 Article 1 Sentence 1 … Link 1
2024-01-01 Article 1 Sentence 2 … Link 1
2024-01-01 Article 1 Sentence 3 … Link 1
2024-01-03 Article 2 Sentence 1 … Link 2

Principle 3: Stay close to your data

👀 Know what to clean

The closer you are to your data, the better you know what needs to be cleaned.

⚙️ Tailor to your dataset

Not all cleaning steps are necessary—it really depends on your data set!

A proposed workflow

2. Preparation: Example with the ETtoday corpus

Playing hide-and-seek with the data

  • Cleaning data is like playing hide-and-seek: randomly scroll through the dataset to spot what needs cleaning.

How to know what to clean?

  • We will almost always miss something on the first pass!
  • Most of the time, we realize we need another cleaning step during the analysis.
  • Having R scripts ready is essential: adding a new step takes seconds instead of redoing everything by hand!

Roadmap for the ETtoday corpus

🔄 Transformations

  • Whole article is in 1 cell \(\rightarrow\) split so 1 cell = 1 paragraph.

🏷️ Annotations

  • Extract year, month, and day into separate columns.

🗑️ Data removal

  • Image legends (▲, ▼, 圖／, 文／)
  • Unrelated ETtoday messages & links
  • Journalist bylines (記者, 實習記者)
  • Data from 2023
  • Empty / whitespace rows
  • Residual HTML tags (<...>)

Step 1: Further annotations (Date metadata)

Extract year, month, and day from the time string using substr():

Article_total$year  <- substr(Article_total$time, start = 1, stop = 4)
Article_total$month <- substr(Article_total$time, start = 6, stop = 7)
Article_total$day   <- substr(Article_total$time, start = 9, stop = 10)

How substr() cuts "2024年01月28日 22:47":

start = 1, stop = 4 \(\rightarrow\) 2024  |  start = 6, stop = 7 \(\rightarrow\) 01  |  start = 9, stop = 10 \(\rightarrow\) 28

Step 2: Split articles into paragraphs

Change the unit of analysis from 1 row = 1 article to 1 row = 1 paragraph:

Article_total$original_article <- Article_total$body

Article_total2 <- Article_total %>% 
  mutate(body = strsplit(as.character(body), "\r\n")) %>% 
  unnest(body)

1. strsplit(..., "\r\n")

Splits the article text at every carriage return (\r\n).

2. unnest(body)

Expands an article with 5 paragraphs into 5 individual rows in Article_total2.

Step 3: Remove unwanted paragraphs

The Golden Rule: Test before you delete!

Every removal step follows the same two-step pattern:

  1. Inspect (+grep): Store matching rows in test to verify we only catch noise.
  2. Remove (-grep): Drop those rows from Article_total2 once verified.
# 1. Test first!
test <- Article_total2[+grep("PATTERN", Article_total2$body), ]

# 2. If acceptable, remove!
Article_total2 <- Article_total2[-grep("PATTERN", Article_total2$body), ]

Example 1: Image Legends

Remove captions and credits containing ▲, ▼, 圖／ (Image), or 文／ (Text):

Article_total2 <- Article_total2[-grep("▲", Article_total2$body),]
Article_total2 <- Article_total2[-grep("▼", Article_total2$body),]

### Check "圖／" (image) and "文／" (text) first
test <- Article_total2[+grep("圖／", Article_total2$body),]
test <- Article_total2[+grep("文／", Article_total2$body),]

### Indeed the case: Can be removed
Article_total2 <- Article_total2[-grep("圖／", Article_total2$body),]
Article_total2 <- Article_total2[-grep("文／", Article_total2$body),]

Example 2: Boilerplate & System Messages

Remove ETtoday interface symbols and cross-article navigation links:

Targeted noise:

  • Symbols: ●, ►, ▸, ★
  • Phrases:
    • 【其他新聞】 (Other news)
    • 更多新聞 (More news)
    • 延伸閱讀 (Read more)
# Symbols (after testing each with +grep)
Article_total2 <- Article_total2[-grep("●", Article_total2$body),]
Article_total2 <- Article_total2[-grep("►", Article_total2$body),]
Article_total2 <- Article_total2[-grep("▸", Article_total2$body),]
Article_total2 <- Article_total2[-grep("★", Article_total2$body),]

# Navigational phrases (after testing each with +grep)
Article_total2 <- Article_total2[-grep("【其他新聞】", Article_total2$body),]
Article_total2 <- Article_total2[-grep("更多新聞", Article_total2$body),]
Article_total2 <- Article_total2[-grep("延伸閱讀", Article_total2$body),]

Example 3: Journalist Identity

Check the first 2 or 4 characters of a paragraph to strip out reporter bylines (記者, 實習記者):

### Check first two characters for "記者" (journalist)
test <- Article_total2
test$FirstTwoCharacters <- substr(Article_total2$body, start = 1, stop = 2)
## Only 178 sentences out of 361,154 wrongly removed -> quite acceptable!

Article_total2$FirstTwoCharacters <- substr(Article_total2$body, start = 1, stop = 2)
Article_total2 <- Article_total2[-grep("記者", Article_total2$FirstTwoCharacters),]
Article_total2$FirstTwoCharacters <- NULL

### Check first four characters for "實習記者" (intern journalist)
Article_total2$FirstFourCharacters <- substr(Article_total2$body, start = 1, stop = 4)
Article_total2 <- Article_total2[-grep("實習記者", Article_total2$FirstFourCharacters),]
Article_total2$FirstFourCharacters <- NULL

Example 4: Date Filtering

Remove rows from 2023 so the corpus only keeps the target year (2024):

Article_total2 <- Article_total2[!(Article_total2$year == "2023"), ]

💡 Why check FirstTwoCharacters for 記者? What would happen if we ran -grep("記者", Article_total2$body) on the entire paragraph instead of the first two characters?

⚖️ Acceptable trade-off: 178 sentences out of 361,154 (~0.05%) are lost. Always weigh precision vs. data loss!

Step 4: Remove empty rows (Part 1: Spaces)

Filter out empty strings ("") and paragraphs made only of spaces (" " up to 5 spaces):

## 1. Empty strings
test <- Article_total2[(Article_total2$body == ""), ]
Article_total2 <- Article_total2[!(Article_total2$body == ""), ]

## 2. Single space (spotted on line 7)
Article_total2$body[7] 
test <- Article_total2[(Article_total2$body == " "), ]
Article_total2 <- Article_total2[!(Article_total2$body == " "), ]

## 3. Multiple spaces (tested 2 to 7 spaces; matches found for 2 to 5 spaces)
Article_total2 <- Article_total2[!(Article_total2$body == "  "), ]
Article_total2 <- Article_total2[!(Article_total2$body == "   "), ]
Article_total2 <- Article_total2[!(Article_total2$body == "    "), ]
Article_total2 <- Article_total2[!(Article_total2$body == "     "), ]

Step 4: Remove empty rows (Part 2: Weird whitespace)

What if a row looks empty during visual inspection, but " " doesn’t catch it?

👉 Extract the unknown character directly by its row number, test it, and remove all matches!

## Visual inspection: Line 7 is still empty! Extract the exact symbol:
ToRemove <- Article_total2$body[7] 
test <- Article_total2[(Article_total2$body == ToRemove), ]
Article_total2 <- Article_total2[!(Article_total2$body == ToRemove), ]

## Repeat the exact same trick for other stubborn empty rows spotted visually:
# Row 13974
ToRemove <- Article_total2$body[2373] 
Article_total2 <- Article_total2[!(Article_total2$body == ToRemove), ]

# Row 965, Row 16121, and Row 23912
ToRemove <- Article_total2$body[965] 
Article_total2 <- Article_total2[!(Article_total2$body == ToRemove), ]

ToRemove <- Article_total2$body[16121] 
Article_total2 <- Article_total2[!(Article_total2$body == ToRemove), ]

ToRemove <- Article_total2$body[23912] 
Article_total2 <- Article_total2[!(Article_total2$body == ToRemove), ]

Step 5: Remove weird scraping instances (HTML)

Use regular expressions (grepl("<[^>]+>", ...)) to catch rows that still contain residual HTML tags (<...>):

## Identify rows containing "<" followed by any characters and ">"
test <- Article_total2
test_HTML <- grepl("<[^>]+>", Article_total2$body)
test$HTML <- test_HTML
test <- test[(test$HTML == "TRUE"), ]

## Indeed corresponds to rows to remove
Article_total2$HTML <- test_HTML
Article_total2 <- Article_total2[!(Article_total2$HTML == "TRUE"), ]

Article_total2$HTML <- NULL
